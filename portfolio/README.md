# Интерактивное портфолио: комната

Сайт-портфолио в виде изометрической комнаты. Посетитель кликает по полу, персонаж идёт; кликает по предмету — персонаж подходит, и открывается раздел. Шкаф открывает гардероб.

Технологии: Phaser 3 (сцена), TypeScript, Vite. Сервера и базы данных нет. Вся графика рисуется кодом, внешних картинок нет, поэтому сайт загружается одним файлом.

## Запуск

```bash
cd portfolio
npm install
npm run dev        # разработка, http://localhost:5173
npm run build      # собирает dist/ (сайт) и dist-embed/portfolio-embed.js (для вставки)
npm test           # тесты поиска пути и проекции
npm run e2e        # проверка в реальном браузере (нужен запущенный `npx vite preview --port 4173`)
```

## Что где менять

| Что | Файл |
|---|---|
| Тексты разделов (резюме, проекты, контакты, видео) | `src/config/sections.ts` |
| Предметы в комнате, их положение, к какому разделу ведут | `src/config/room.ts` |
| Варианты одежды, причёсок, цветов | `src/config/wardrobe.ts` |
| Название сайта в шапке, скорость ходьбы | `src/config/settings.ts` |
| Внешний вид предметов | `src/game/draw/furniture.ts` |
| Внешний вид персонажа | `src/game/draw/character.ts` |
| Цвета и стиль интерфейса | `src/ui/styles.ts` |

Все тексты разделов сейчас — **демо-заглушки**. Реальных данных в проекте нет.

### Добавить предмет и связать с разделом

1. В `src/config/sections.ts` добавьте раздел (id, заголовок, блоки контента).
2. В `src/config/room.ts` добавьте объект в `FURNITURE`:
   - `kind` — вид предмета (из `DRAWERS` в `furniture.ts`; для нового вида допишите функцию рисования);
   - `gx, gy, w, d` — клетка и размер на полу (комната 10×10 клеток);
   - `interactive` — подсказка, клетки подхода (`approach`), куда смотреть (`face`), действие (`action`).
3. Больше ничего менять не нужно: наведение, подход, поиск пути, маркер и окно работают по общим правилам.

Типы действий (`action.type`): `modal` (окно по центру), `panel` (панель сбоку), `link` (внешняя ссылка), `page` (переход на страницу), `wardrobe` (гардероб), `special` (особое действие, сейчас `sit` — присесть).

Передвинуть мебель — изменить `gx, gy` у объекта. Логика взаимодействий не меняется.

### Заменить рисованную графику на свою

Персонаж собирается из слоёв (волосы сзади, тело, низ, обувь, верх, волосы спереди, аксессуар). У каждого слоя есть кадры: ожидание, ходьба (6 кадров), взаимодействие, сидение; виды спереди и сзади (поворот влево-вправо делается отражением). Ключи кадров формирует `frameKey()` в `character.ts`. Чтобы подключить готовые спрайты, подмените в `ensureCharacterTextures` генерацию кадров на загрузку ваших изображений под теми же ключами.

## Адреса разделов

Раздел открывается по адресу: `#/resume`, `#/projects`, `#/video`, `#/contacts`, `#/wardrobe`. Ссылку можно отправить. Для людей без мыши есть меню «Разделы» и управление клавиатурой (стрелки или WASD, E — действие рядом, Esc — закрыть).

## Вставка в Tilda

Вариант А (рекомендуется): разместить папку `dist/` на любом хостинге (GitHub Pages, свой сервер) и вставить в блок T123 «HTML»:

```html
<iframe src="https://ВАШ-АДРЕС/" style="width:100%;height:80vh;border:0" loading="lazy" allow="fullscreen"></iframe>
```

Вариант Б: один скрипт без iframe. Разместить `dist-embed/portfolio-embed.js` на хостинге и вставить в блок T123:

```html
<div data-avatar-portfolio style="height:80vh"></div>
<script src="https://ВАШ-АДРЕС/portfolio-embed.js"></script>
```

В варианте Б интерфейс изолирован Shadow DOM, стили страницы Tilda его не затрагивают (проверено на тестовой странице со специально «враждебными» стилями, не на реальной Tilda). Адрес страницы при этом не меняется; чтобы включить адреса разделов, добавьте атрибут `data-routing="hash"`.

## Хранение данных

Выбранный образ персонажа сохраняется в `localStorage` браузера. Если хранилище недоступно, сайт работает с образом по умолчанию.

## Известные ограничения первой версии

- Одна комната. Несколько локаций не делались, пока не готова базовая.
- Графика процедурная (в стиле «наклейки»), это основа для замены на авторскую.
- Не проверялось на реальной Tilda и на реальных телефонах: только Chromium с эмуляцией мобильного экрана.
- Размер скрипта около 1,2 МБ (340 КБ в gzip), из них основная часть — сам Phaser.

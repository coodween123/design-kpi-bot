# Stones — лендинг

React 18 + TypeScript + Vite + Tailwind CSS 3, иконки lucide-react.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # проверка типов + сборка в dist/
```

## Медиа

- `src/assets/base.png` — базовый слой (сухая скала). Это исходная картинка, вписанная в кадр 16:9 видео
  (масштаб 0.712, сдвиг 13.5 / −3.5 px относительно кадра 1280×720), сохранена в 1920×1080.
  Видео было сгенерировано из этой картинки, но перекадрировано в 16:9, поэтому без подгонки слои не совпадали.
- `public/reveal.mp4` — видео с цветущей скалой, без изменений. Проигрывается вперёд и перезапускается через `loop`.
